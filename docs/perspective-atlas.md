## 本轮结果

原仓库已经包含用户提供的九篇中文正文及九篇完整英文译文，日期均为 2026-11-18，且均为公开文章。已逐篇核对原稿，没有重复创建或替换正文。

专题首屏增加作者两组论证的红蓝对照，明确说明这不是当事人的直接交锋。完整文章依旧使用现有 Markdown 路由和文章列表。

共享时间轴现有 20 条记录，七类参与方包含黄仁勋、英伟达、美国政府、美国总统、企业家、投资人士和媒体。人物档案聚合相同数据源，可比较两个人物，按日期排序；没有来源的历史观点不会自动补造。

终章 Markdown front matter 新增 `authorOpinion`，包含结论、依据、概率、复盘观察条件和关联链接。概率保持 `null / unspecified`，未替作者补造数值。复盘状态保持 `pending`；失效条件是根据文章整理的后续观察点，可由作者继续调整。

分享弹窗提供事件摘要、作者观点对照和文章摘要三类卡片，可复制链接、下载 PNG 或打开浏览器支持的系统分享面板。中英文 Open Graph 预览图保存在 `public/og/`，对应 SVG 源文件也已保留。

## 内容与数据维护

- `content/perspectives/index.ts`：事件注册表。
- `content/perspectives/jensen-huang.ts`：首期专题、参与方、观点阵营、时间轴、文章关联及来源核验状态。
- `lib/perspectives.ts`：数据类型。阵营使用可扩展数组和字符串 ID，可表示三方及更多观点。
- `relationship`：区分公开表态、观点不同、直接回应、媒体解读及后续补充。只有原始证据支持时才应标记直接回应。
- `verification`：记录和来源分别维护。一个可访问的参考链接，不会自动证明同一记录里的所有论断。
- `archiveSlug`：人物档案静态路由。新增事件后，同一人物的记录可以继续汇入档案；当前专题入口仍以首期黄仁勋事件为主，后续多事件入口应同步扩展路由。

逐项来源核验结果见 [来源检查记录](perspective-atlas-sources.md)。网络受限与链接失效分别记录，不能将访问失败直接解释为说法不实。
